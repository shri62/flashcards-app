## Reflection: AI Coding Challenge

- **Where AI saved time:** AI helped me write HTML, CSS, and JavaScript code faster. It helped me add features like creating decks, managing flashcards, searching cards, and saving data.

- **AI bug I identified and fixed:** When I searched for a word that did not match any flashcard, I checked whether the app showed a helpful message. I tested the search and empty-state behavior to make sure users knew when no cards were found.

- **Code I refactored:** I organized my JavaScript into smaller functions, such as `renderDeckList()`, `renderStudyArea()`, and `saveState()`. Each function has a specific job, making the code easier to read and understand.

- **Accessibility improvement:** I worked on adding helpful labels, keyboard controls, and visible focus styles so users can navigate and use the app more easily.

- **How I improved my prompts:** I learned to give AI clear instructions, ask for one feature at a time, and request simple explanations. I also asked for ways to test the code so I could check whether the features worked correctly.
